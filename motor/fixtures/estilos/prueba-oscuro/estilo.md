# prueba-oscuro (estilo de desarrollo del motor)

Solo para probar el motor mientras el catálogo `estilos/` no esté completo. Azul marino tipo `curso-azul`, con las
variantes que el catálogo real no usa: paneles de **cristal**, fondo de **rejilla**, transición de **bloques** y
palabra activa en el color del **capítulo**. 3D estándar. Tipografía Montserrat (OFL).
